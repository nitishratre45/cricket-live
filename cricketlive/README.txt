CRICKET LIVE - VERCEL

1. Upload these files to a GitHub repository.
2. Import the repository into Vercel.
3. Before deploying, edit app.js.
4. Replace PASTE_PUBLIC_HLS_URL_HERE with the public HLS URL of your authorized stream.
5. Deploy.

IMPORTANT:
Vercel hosts the website/player. The live video must come from a reachable HLS stream server.
Do not put private stream keys or credentials in app.js.
